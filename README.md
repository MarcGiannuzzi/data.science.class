# Data Science Class

Curated collection of data science and ML learning materials, organized as git submodules.

## Modules

| Module | Description |
|--------|-------------|
| [gcp-ml-cheatsheet](gcp-ml-cheatsheet/) | GCP Professional ML Engineer certification cheatsheets |

## Setup

```bash
git clone --recurse-submodules https://github.com/MarcGiannuzzi/data.science.class.git
```

To update all submodules:

```bash
git submodule update --remote --merge
```
