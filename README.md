# Data Science Class

Curated collection of data science and ML learning materials, organized as git submodules.

## Modules

| Module | Description |
|--------|-------------|
| [gcp-ml-cheatsheet](gcp-ml-cheatsheet/) | GCP Professional ML Engineer certification cheatsheets |
| [stanford-cs-229-machine-learning](stanford-cs-229-machine-learning/) | Stanford CS 229 Machine Learning cheatsheets (Shervine Amidi) |
| [stanford-cs-230-deep-learning](stanford-cs-230-deep-learning/) | Stanford CS 230 Deep Learning cheatsheets (Shervine Amidi) |
| [stanford-cs-221-artificial-intelligence](stanford-cs-221-artificial-intelligence/) | Stanford CS 221 Artificial Intelligence cheatsheets (Shervine Amidi) |
| [stanford-cme-295-transformers-large-language-models](stanford-cme-295-transformers-large-language-models/) | Stanford CME 295 Transformers & LLMs cheatsheet (Shervine Amidi) |
| [stanford-cme-296-diffusion-large-vision-models](stanford-cme-296-diffusion-large-vision-models/) | Stanford CME 296 Diffusion & Large Vision Models cheatsheet (Shervine Amidi) |

## Setup

```bash
git clone --recurse-submodules https://github.com/MarcGiannuzzi/data.science.class.git
```

To update all submodules:

```bash
git submodule update --remote --merge
```
